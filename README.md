# FotoVoz

Estudio local de **video narrado por etapas**: fotos + carteles + narración en
español → MP4 listo para redes (vertical 9:16, cuadrado 1:1 u horizontal 16:9).

Este repo es el **canal de distribución**: las descargas (portable + instalador)
viven en [Releases](https://github.com/romantitoavalos/fotovoz-app/releases).
La app consulta automáticamente `releases/latest` para avisar de versiones
nuevas y aplicarse sola (sin token, sin configuración).

## Descargar

- **Portable:** descomprimir `FotoVoz-para-cliente.zip` y ejecutar
  `FotoVoz.exe`. Sin instalación.
- **Instalador:** ejecutar `FotoVoz-Setup-<ver>.exe` (per-user, sin admin).

→ https://github.com/romantitoavalos/fotovoz-app/releases/latest
